# Home screen v1 (navy theme, CSS illustrations)

Snapshot of the Home screen before the laptop-repair redesign, so it can be restored.

Files:

- `index.tsx` → `src/app/index.tsx`
- `app.json` → `app.json`
- `animated-icon.tsx` → `src/components/animated-icon.tsx`
- `animated-icon.module.css` → `src/components/animated-icon.module.css`

Restore from the repository root:

```bash
cp backups/home-screen-v1/index.tsx src/app/index.tsx
cp backups/home-screen-v1/app.json app.json
cp backups/home-screen-v1/animated-icon.tsx src/components/animated-icon.tsx
cp backups/home-screen-v1/animated-icon.module.css src/components/animated-icon.module.css
```
